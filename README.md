## 规则

- 每题独立 `.cpp` 文件，命名格式：`题号+题目简称.cpp`
- 同一题有多种解法时，全部写在**同一个** `.cpp` 里，用并列的多个 `class Solution` 区分，每块上方加一行 `//` 注明解法
